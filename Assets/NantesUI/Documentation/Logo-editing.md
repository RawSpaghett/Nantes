# Editing the logo

The editable files are in [Design/Logo](../../../Design/Logo) on the `dev_ui` branch:

- [Nantes-Logo-Original.svg](../../../Design/Logo/Nantes-Logo-Original.svg): six editable vector letters.
- [Nantes-Logo-Original.psd](../../../Design/Logo/Nantes-Logo-Original.psd): six pixel layers, one per letter, on a transparent background.
- [Nantes-Logo-Original.png](../../../Design/Logo/Nantes-Logo-Original.png): transparent export.

Use the SVG for shape changes or the PSD for pixel edits. The letters are shapes and pixels, not editable text. Export over [NantesLogo.png](../Logo/NantesLogo.png) for Unity. Keep the background transparent.

The font is Nantes Display, a modified Michroma with an open A. See the [font license](Licenses/OFL.txt).

The glitch and ship overlap are Unity effects; they are not part of the artwork.
