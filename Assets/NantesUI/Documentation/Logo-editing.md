# Editing the logo

The current files are in [Design/Logo](../../../Design/Logo):

- `Nantes-Logo-Original.svg`: six editable vector letters.
- `Nantes-Logo-Original.psd`: six letter layers on a transparent background.
- `Nantes-Logo-Original.png`: transparent export.

Use the SVG for shape changes or the PSD for pixel edits. Export over [NantesLogo.png](../Logo/NantesLogo.png) for Unity. Keep the background transparent.

The font is Nantes Display, a modified Michroma with an open A. See the [font license](Licenses/OFL.txt).

The glitch and ship overlap are Unity effects; they are not part of the artwork.
